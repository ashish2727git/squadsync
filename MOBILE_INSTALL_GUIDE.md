# SquadSync - Mobile Installation Guide

## 📱 Install SquadSync as a Mobile App

SquadSync is a **Progressive Web App (PWA)** that can be installed on your mobile device and used like a native app!

### ✨ Benefits of Installing
- 🚀 **Instant Access** - Launch from your home screen
- 📴 **Works Offline** - Basic functionality works without internet
- 🔔 **Push Notifications** - Get summon alerts instantly (coming soon)
- 📱 **Full Screen** - No browser UI, just the app
- ⚡ **Faster Loading** - Cached for quick startup

---

## 📲 Installation Instructions

### For Android (Chrome/Samsung Internet)

#### Method 1: Install Prompt
1. Open Chrome browser on your Android phone
2. Navigate to **http://yourserver:3000** (or your deployment URL)
3. You'll see a banner at the bottom: **"Add SquadSync to Home screen"**
4. Tap **"Install"** or **"Add"**
5. Confirm by tapping **"Add"** again
6. Done! SquadSync icon will appear on your home screen

#### Method 2: Manual Installation
1. Open Chrome and go to http://yourserver:3000
2. Tap the **⋮** (three dots) menu in the top right
3. Select **"Add to Home screen"** or **"Install app"**
4. Name it "SquadSync"
5. Tap **"Add"**
6. The app icon will appear on your home screen

### For iPhone/iPad (Safari)

1. Open **Safari** browser (must use Safari, not Chrome)
2. Navigate to **http://yourserver:3000**
3. Tap the **Share** button (📤 box with arrow) at the bottom
4. Scroll down and tap **"Add to Home Screen"**
5. Name it "SquadSync"
6. Tap **"Add"** in the top right
7. SquadSync will appear on your home screen

### For Desktop (Chrome, Edge, Brave)

1. Open Chrome/Edge/Brave browser
2. Navigate to http://yourserver:3000
3. Look for the **⊕ Install** button in the address bar
4. Click **"Install"**
5. SquadSync will open as a desktop app
6. You can pin it to your taskbar for quick access

## 🔧 Troubleshooting

### "Add to Home Screen" Not Showing

**On Android:**
- Make sure you're using Chrome or Samsung Internet
- Clear browser cache and try again
- Check if the site is already installed

**On iPhone:**
- Must use Safari browser (not Chrome)
- iOS 11.3 or higher required
- Make sure you're not in Private Browsing mode

### App Won't Install
1. Clear browser cache
2. Check if you already have the app installed
3. Try a different browser
4. Restart your phone and try again

### App Icon Missing After Install
1. Check your app drawer (Android) or home screen pages
2. Try reinstalling
3. Reboot your device

### App Shows "No Internet" Error
- Check your internet connection
- Make sure the server is running
- Verify the URL is correct (http://yourserver:3000)

### Can't Login After Installing
1. Clear app data (Android: Settings > Apps > SquadSync > Storage > Clear Data)
2. Uninstall and reinstall the app
3. Try logging in through the browser first, then install

## 🗑️ Uninstalling the App

### Android
1. Long-press the SquadSync icon
2. Select **"Uninstall"** or drag to "Remove"
3. Confirm

**Or:**
1. Go to Settings > Apps
2. Find "SquadSync"
3. Tap "Uninstall"

### iPhone/iPad
1. Long-press the SquadSync icon
2. Tap "Remove App"
3. Select "Delete App"
4. Confirm

### Desktop
1. Right-click the app icon
2. Select "Uninstall" or "Remove from Chrome"
3. Confirm

## 💡 Tips for Best Experience

### Battery Optimization
- On Android: Add SquadSync to "unrestricted" apps to receive notifications
- Go to Settings > Battery > Battery Optimization > Find SquadSync > Don't Optimize

### Notifications (Coming Soon)
- Enable browser notifications when prompted
- Check phone notification settings for SquadSync
- Keep app updated for latest features

### Performance
- Clear app cache periodically (Settings > Apps > SquadSync > Storage > Clear Cache)
- Keep only 3-4 active squads for best performance
- Close other apps when using voice chat

### Data Usage
- Voice chat uses ~1-2MB per minute
- Real-time features use minimal data (~100KB/hour)
- Enable "Data Saver" mode in settings (coming soon)

## 🔄 Updating the App

PWAs update automatically when you use them!

- App checks for updates when launched
- Updates download in background
- Restart app to apply updates
- You'll see a refresh prompt if major update

**Manual Update:**
1. Close the app completely
2. Clear browser cache
3. Reopen the app

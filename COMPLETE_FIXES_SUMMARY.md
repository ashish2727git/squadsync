## 🗺️ COMPLETE USER FLOW

### **Path 1: Create & Manage Squad**

```
START
  ↓
Login/Register
  ↓
Dashboard (See welcome message)
  ↓
Click "Create Squad" (Big green card)
  ↓
Fill Form:
  - Squad Name ✓
  - Game (optional)
  - Description (optional)
  - Max Members
  ↓
Click "Create Squad" button
  ↓
Back to Dashboard → See new squad card
  ↓
Click "View Details" button on squad
  ↓
Squad Detail Page:
  - See members
  - See schedule
  - See events
  ↓
Click "Invite Link" button
  ↓
Copy link → Share with friends
  ↓
Friends click link → Join squad
```

### **Path 2: Use Vault**

```
Dashboard
  ↓
Click "Open Vault" (Big purple card)
  ↓
Vault Page
  ↓
Click "+ New Item" button
  ↓
Fill Form:
  - Name
  - Description
  - Type (loadout/clip/achievement)
  - Privacy (private/shared)
  ↓
Click "Create" button
  ↓
See item in vault
  ↓
Click "Delete" to remove
```

### **Path 3: War Room Collaboration**

```
Dashboard
  ↓
Find squad card
  ↓
Click "War Room" button
  ↓
War Room Page:
  - Whiteboard (draw strategies)
  - Chat (text messages)
  - Voice (talk to team)
  - Screen share
  ↓
Collaborate in real-time
```

## 🚀 **HOW TO START (RIGHT NOW!)**

### **Step 1: Open the App**

**On Computer:**
```
http://localhost:3000
```

**On Mobile (same WiFi):**
```
http://192.168.1.5:3000
```

### **Step 2: Register Account**

1. Click "Create Account"
2. Enter your details:
   - **Username:** Choose 3-50 characters
   - **Email:** your@email.com
   - **Password:** 8-72 characters (watch the strength meter!)
     - Example: `MySquad@2026!`
     - Must have: uppercase, lowercase, number, symbol
   - **Confirm Password:** Same as above

3. Click "Create Account" →

4. **✅ SUCCESS!** You'll land on the dashboard!

### **Step 3: Explore Features**

**On Dashboard:**
- View your squads

1. Click "Create Squad" button
2. Enter squad details
3. Invite members
4. Start coordinating!

## 🔧 **TROUBLESHOOTING:**

### **Can't Access?**
- Check services: `docker-compose ps` (all should be "Up")
- Restart: `docker-compose restart`

### **Mobile Can't Connect?**
- Same WiFi as computer?
- Firewall: Run `enable-firewall-access.bat` as admin
- Try: `http://192.168.1.5:3000`

### **Registration Fails?**
- Password 8-72 characters?
- Has uppercase, lowercase, number, symbol?
- Passwords match?

### **White Page?**
- Refresh browser (Ctrl+F5)
- Clear cache
- Try different browser
